O HŘE

Hádej sakra je bezplatná česká open source zeměpisná alternativní hra k známé online hře GeoGuessr.

 

Hra primárně využívá panoramata (poslední snímkování probíhalo v letech 2021 až 2023), mapové dlaždice, našeptávač míst a další mapové funkce od společnosti Seznam prostřednictvím jejich REST API Mapy.com a JS Panorama, a také knihovnu Leaflet pro zobrazení mapy a veškerou práci s ní.

 

Hru si můžeš jakkoliv ztížit či zjednodušit pomocí spousty nastavení, které si navolíš bezprostředně před zahájením tvého hádání po České republice.

 

Hra není optimalizována pro mobilní zařízení z důvodu ne moc dobrého ovládání.

 

Jelikož hra využívá zvýhodněný tarif REST API Mapy.cz, který nabízí 10 000 000 kreditů měsíčně zdarma, tak po spotřebování všech těchto kreditů nebude hra funkční a budeš muset počkat na začátek dalšího měsíce, kdy se tyto kredity znovu obnoví.

 

Hra zpřístupněna veřejnosti na začátku července 2023 na již zastaralé knihovně JS SDK Mapy.cz.

Na začátku července 2024 byla hra kompletně předělána na nové REST API Mapy.cz a JS Panorama společně s mapovou knihovnou Leaflet.

 

 

Web využívá:

Panoramata, mapové dlaždice, našeptávač míst a další mapové funkce - REST API Mapy.com a JS Panorama

Mapovou knihovnu - Leaflet

Leaflet rozšíření pro zjištění, zdali se bod nachází uvnitř polygonu - Leaflet.PointInPolygon

SVG mapu České republiky - SimpleMaps

Vzorce pro výpočet vzdálenosti, směru a zeměpisných souřadnic - Movable Type Ltd

Zeměpisná data (souřadnice míst v herním módu Specifická místa v ČR) - OpenStreetMap

Webové technologie HTML, CSS a JS

Ukládání dat (statistiky, historie her) do lokálního uložiště prohlížeče

Webovou analytiku - Beam Analytics a GoatCounter
